# AI Student OS

AI Student OS is a personal productivity and learning system designed for university students.

Its goal is to help students organize school work, personal development, and daily life in one place.

## Why I am building this

University students often have tasks scattered across different places:

- university learning platforms
- WhatsApp
- Google Calendar
- notes
- reminders
- assignment documents

At the same time, students also need to manage personal development, such as:

- IELTS
- programming
- portfolio projects
- internship preparation
- job applications

AI Student OS aims to answer one simple question:

> What should I do next?

## Core Categories

### SCHOOL

University-related tasks.

Examples:

- lectures
- assignments
- quizzes
- exams
- Final Year Project

### GROWTH

Personal development and career preparation.

Examples:

- IELTS
- programming practice
- portfolio projects
- internship preparation
- CV improvement

### LIFE

Daily life and personal tasks.

Examples:

- appointments
- errands
- travel
- shopping

## MVP

The first version will be able to:

- store tasks
- divide tasks into SCHOOL, GROWTH, and LIFE
- assign priorities
- track task status
- display current tasks

## Future Features

Possible future features include:

- Google Calendar integration
- automatic scheduling
- AI task prioritization
- reminders
- study analytics
- web dashboard
